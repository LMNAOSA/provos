# Build checklist

1. Confirm the authoritative `Matrixtwin_opal.glb` at the repository root is committed to GitHub.
2. Run `npm install`.
3. Run `npm run build`.
4. Deploy to Vercel.
5. Confirm the browser can fetch the Matrix Twin from `NEXT_PUBLIC_SPECIMEN_MODEL_URL` (default GitHub raw URL).
6. Test Case 001 through all six stages on desktop and mobile.
