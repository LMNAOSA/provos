# ProvenanceOS™ — The Andamooka Experiment

Interactive Next.js prototype for the Australian Provenance Project.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel

Connect the GitHub repository to Vercel. The default Next.js build works without a custom Vercel configuration.

## What is real vs simulated

The live case, specimen 3D form, evidence values and expert scenario are **demonstration content**. They deliberately do not claim to be authenticated scientific measurements or actual quotations from the named experts.

Replace content in `app/data/scenario.ts` and the future API/tool layer with approved Phase One material before external scientific use.
